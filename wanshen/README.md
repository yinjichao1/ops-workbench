## 四、校验规则清单

### 硬伤级（拦截提交）
- 全部必填项空缺
- 身份证 18 位校验位算法（含出生年月合法性、出生日期与身份证一致性）
- 手机号 11 位格式、邮箱格式、邮编 6 位
- 证件照：120*160px ~ 600*800px、JPG/PNG、5~200kb、宽高比 3:4
- 学籍验证码位数与字符集
- 身高 130~230cm / 体重 30~200kg 数值范围
- 教育经历起止时间逻辑（开始 ≤ 结束）
- 教育经历、家庭成员必填模块非空

### 风险级（报告提示）
- 籍贯与生源省份不一致
- 最高学历结束时间与毕业时间不符
- BMI 偏高 / 健康状况选择"否"
- 手机号为 17 号段（短信送达率）
- 家庭成员工作单位与职务表述矛盾

### 提示级（竞争力优化）
- 外语/计算机/获奖/实践/证书/附件/求职意向/学术成果 缺项提醒
- 公共邮箱提醒
- 预备党员转正时间提醒
- 生源地与目标省公司匹配建议

## 五、体检报告评分逻辑

```
基础分 = 完整度达标基数 + 填充率加权
扣分   = 硬伤 × 12 + 风险 × 4
综合评分 = clamp(基础分 - 扣分, 0, 100)

≥90 优秀 · 可以直接提交
≥75 良好 · 建议微调后提交
≥60 及格 · 存在明显缺项
<60 待完善 · 缺项较多
```

报告页末尾含 **CTA 转化区（预约网申诊断）**，为留资钩子的核心出口。

## 七、后端 + 部署（2026-09-30 已上线）

**后端**（挂 ops-workbench，`app/routes/ws_apply.py` + `app/models/ws_apply.py`）：

| 接口 | 鉴权 | 说明 |
|---|---|---|
| POST `/api/public/apply/submit` | 公开（nginx /api/public/ 白名单） | 提交档案，载荷 `{summary, archive, platform}` |
| GET `/api/apply/list` | Basic Auth | 档案列表（分页+搜索） |
| GET `/api/apply/detail/{id}` | Basic Auth | 完整档案 + 多行明细 |
| GET `/api/apply/export` | Basic Auth | 导出 CSV（UTF-8 BOM） |
| DELETE `/api/apply/{id}` | Basic Auth | 删除档案+明细+对应线索摘要（清理测试数据用） |

**落库方案**：
- `ws_archives` 完整档案 JSON 快照 + 摘要列（姓名/电话/学校/专业/学历/评分/硬伤/风险/完整度/渠道/IP）
- `ws_archive_items` 多行明细子表（教育经历/家庭成员/外语/计算机/证书/实践/论文/科研/获奖/附件 逐行）
- `leads` 线索表同步写一条摘要（source=**网申模拟**，姓名/电话/学校/年级）；注意 leads 每周 CSV 按周替换，摘要行可能被当周替换清掉，完整档案以 ws_archives 为准
- 附件 base64 不落库（只存名称/类型/大小），证件照 base64 保留；档案 JSON 上限 2MB
- 同手机号当日重复提交 → 更新原档案（渠道以首次为准）；同 IP 10 分钟限 5 次

**前端配置**：`index.html` 内 `window.SG_SUBMIT_ENDPOINT`，线上同源直连 `/api/public/apply/submit`，其他环境回退主域。

**线上地址**：`https://sigedianwang.cn/ws/`（nginx 静态托管，Cloudflare Tunnel）

**分发（下一轮）**：生成二维码，扫码 → 填写 → 体检报告 → 预约诊断。
